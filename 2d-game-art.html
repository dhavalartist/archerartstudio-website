FAQ

2D Game Art FAQ

What types of 2D game art do you create?

Archer Art Studio creates character art, concept art, illustrations, visual-development artwork, environments, props, key art and promotional artwork for games and interactive projects.

Can you create 2D character concepts for a new game?

Yes. Character development can begin with visual exploration and concept work before moving toward polished production artwork.

Do you provide ongoing 2D game art production?

Yes. Archer Art Studio can support individual deliverables, project-based production and ongoing art requirements depending on the project's scope.

Can you work with an existing art direction?

Yes. We can work from established references, visual direction and existing project requirements to maintain consistency across new artwork.

Can Archer Art Studio handle both 2D and 3D artwork?

Yes. Archer Art Studio provides both 2D and 3D game art, allowing projects that require multiple types of artwork to work with one creative partner.
