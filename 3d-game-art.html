FAQ

Questions about
3D game art?

What types of 3D game assets do you create?

We create 3D characters, props, vehicles, environment assets, mascots and other production assets for games and interactive experiences.

Can you work from existing concepts?

Yes. We can work from supplied concepts, sketches, references or an established art direction and develop the required 3D assets.

Can you create production-ready game assets?

Yes. Asset requirements can be planned around the intended production pipeline, platform and project specifications.

Can you support ongoing 3D production?

Yes. Archer can provide flexible support for individual assets, batches of assets or longer-term production requirements.

Can you support Unity projects?

Yes. Archer also provides Unity development and integration support when the project requires both art and interactive production.
