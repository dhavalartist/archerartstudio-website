FEATURED PROJECT · KANGAROO KHAOS

THE PROJECT

From a rough sketch to a game-ready character.

Kangaroo Khaos is a stylized 3D endless-runner concept built around a memorable kangaroo protagonist. The work spans visual development and production rather than stopping at a single final render.

The case study shows how Archer can move between concept art, 3D production, technical setup and interface design while keeping one visual direction consistent.

02 · CHARACTER DEVELOPMENT

Sketch. Shape. Build.

The character evolved through hand-drawn exploration, color development, 3D modeling and technical rigging. Each stage adds information while keeping the personality intact.

DESIGN DIRECTION

Personality first. Production ready.

Every decision was made to keep the kangaroo expressive, readable and easy to animate in a fast-moving game environment.

03 · 3D PRODUCTION

Built for movement, not just presentation.

The Blender setup shows the character being prepared for controlled movement. Rigging, deformation and multiple viewpoints are part of the production story.

A complete game world needs more than a character.

Alongside the character work, the project explored menus, HUD, customization, shop, rewards, leaderboard, settings and retention screens.

The project demonstrates end-to-end game art capability.

From the first character sketch to the final interface system, Kangaroo Khaos shows the kind of connected production support Archer Art Studio can provide for studios, indie teams and long-term game projects.
